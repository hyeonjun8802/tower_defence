# Battle Plate / Drag Visual Update (v88)

Scope: battle screen rendering only.

## Changes
- Skill plate rendering was toned down visually while preserving gameplay plate keys and rule colors.
- Special plates now use a dimmer neon route-like frame instead of heavy solid blocks.
- Plate symbols/labels were reduced slightly and softened so they do not dominate the board.
- Dragged tower preview is now smaller, more transparent, and lower in tone.
- Drag target tower now eases down in scale while hovered during drag.
- On release, the placed/merged tower gets a short rebound animation back to normal size.

## Not changed
- Plate rules / terrain keys / tower bonuses.
- Enemy route logic.
- Stage map / galaxy map / unlock logic.
