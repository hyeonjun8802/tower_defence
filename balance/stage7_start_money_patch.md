# Stage 7+ Starting Crystal Patch v2

목표: 7-1부터 체감 난이도가 급상승하지 않도록, 스테이지 7 이상에서 시작 즉시 타워 5개를 소환할 수 있는 시작 수정을 지급한다.

## 변경 범위
- 스테이지 1~6 시작 수정: 기존 420 유지
- 스테이지 7 이상 시작 수정: 해당 스테이지의 1웨이브 소환 비용 × 5 이상으로 보정
- 몬스터 HP/속도/웨이브/장판/타워/스테이지 클리어 타이머 UI는 변경하지 않음

## 의도
- 7-1 진입 시 초반 타워 수 부족으로 급격히 밀리는 문제 완화
- 7 이후 스테이지의 첫 웨이브 안정성 확보
- 기존 Stage 7+ 난이도 완화, 장판 상향, Stage 5 BGM, 강화관리 UI, 스테이지 클리어 자동 타이머 수정 유지
- 세로/가로 UI 레이아웃은 변경하지 않음
