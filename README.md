# Planet Rift Defense: Cosmic Plates

행성 디펜스 + 장판 성장 + 뱀파이어 서바이버즈식 랜덤 스킬 선택을 합친 모바일 대응 HTML5 프로토타입입니다.

## 실행 방법

```bash
cd planet_rift_defense
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속 후 실행합니다.

Windows에서는 `run_localhost.bat`, macOS/Linux에서는 `run_localhost.sh`를 실행해도 됩니다.

## 이번 버전에서 수정된 핵심

- 스테이지별 배경 이미지를 CSS 배경이 아니라 **게임 캔버스 내부에 직접 drawImage로 렌더링**합니다.
- 게임판 내부에도 별 전용 레이어를 추가해, 하얀 별들이 실제로 흐르듯 움직입니다.
- 스테이지별로 별 이동감이 조금씩 달라집니다.
- 실제 오디오 파일을 `audio/` 폴더에 추가했습니다.
- BGM 버튼을 누르면 현재 스테이지에 맞는 루프 BGM이 재생됩니다.
- 공격/피격/병합/레벨업/보물/전술 스킬 효과음이 실제 wav 파일로 재생됩니다.

## 조작

- 드래그/터치 드래그: 행성 이동 또는 같은 종류/레벨 병합
- 더블클릭: 타겟 모드 변경
- 1: 소환
- 2: 속도 변경
- Space: 일시정지
- Q/W/E: 전술 스킬
- BGM ON/OFF: 사운드 토글

## 포함 리소스

- `space_bg.png`: 공허 성역
- `bg_ice.png`: 빙결 외곽
- `bg_lava.png`: 용암 성운
- `bg_jungle.png`: 생체 정글
- `audio/bgm_*.wav`: 스테이지별 BGM
- `audio/sfx_*.wav`: 게임 효과음

## v6 업데이트

- 6종 아군 유닛을 24프레임 스프라이트 시트로 교체했습니다.
- 유닛 크기를 줄이고 정면형 디자인을 사용하도록 렌더링 방식을 변경했습니다.
- EXP는 `현재/필요치`와 별도 EXP 바를 표시하며, EXP가 실제로 필요치 이상일 때만 레벨업 스킬창이 뜨도록 수정했습니다.
- 맵을 8x8로 확장해 행성 배치 공간을 늘렸습니다.
- 몬스터 체력/속도/방어 계수를 상향해 난이도를 올렸습니다.
- 스테이지별 전체 맵 임팩트 PNG 페이드 효과를 추가했습니다.
- 얼음 성역은 일부 행성을 잠시 빙결, 용암 성운은 적 방어력 상승, 생체 정글은 공격속도 저하 효과가 발생합니다.


## v7 프레임 정렬 보정

- 24프레임 유닛 스프라이트 시트를 자동 분석해 각 프레임의 유닛 중심을 재정렬했습니다.
- 렌더링은 cover 크롭 방식 대신 center/contain에 가까운 방식으로 바꿔 프레임 전환 시 깨지거나 뒤틀려 보이는 현상을 줄였습니다.
- 유닛 렌더링 크기를 소폭 줄여 프레임 가장자리 잘림을 완화했습니다.


## v9 균일 마진 보정

- 프레임마다 알파 bbox를 측정한 뒤, 각 유닛 시트별로 중앙 기준의 공통 컨텐츠 박스 크기(중앙 너비/높이)를 잡았습니다.
- 각 프레임의 내용을 그 공통 박스 안에 동일 비율로 맞춰 리사이즈하고, 정확히 중앙에 다시 배치했습니다.
- 즉, 단순 중심 정렬이 아니라 `공통 너비/높이 + 동일한 여백` 기준으로 재정렬한 버전입니다.


## v10 정확한 마진 통일

- v9에서 비율 보존으로 인해 상하 마진이 계속 달라지는 프레임이 남아 있었습니다.
- 이번 버전은 각 프레임 bbox를 동일한 공통 너비/높이로 강제 정규화한 뒤 중앙에 배치해, 실제 표시 마진이 정확히 더 균일해지도록 수정했습니다.
- 즉, 약간의 형태 왜곡을 감수하고라도 `보이는 여백`을 우선 통일한 버전입니다.


## v11 미세 프레임 애니메이션

- 유닛은 제자리에서 고정되고, 24프레임 이미지만 순환되어 `살아있는 느낌`만 살짝 나도록 조정했습니다.
- 위아래로 흔들리는 부유감과 과한 펄스/회전 표현은 제거했습니다.
- 사이드 카드 썸네일은 고정 프레임으로 보여 UI가 덜 산만합니다.


## v12 히든 행성 + 공명 스킬 트리

- 소환은 랜덤 소환만 가능하도록 변경했습니다.
- 하단 행성 리스트는 더 이상 직접 소환용이 아니라 `공명 스킬 트리` 역할을 합니다.
- 레벨업 시 코어 포인트를 획득하며, 하단 카드 클릭으로 해당 행성 계열 공격력을 +8%씩 강화할 수 있습니다.
- 기본 행성 6종을 모두 Lv.5 이상으로 모으면 자동으로 `히든 스타 엔진`으로 융합됩니다.
- 히든 스타 엔진은 높은 치명타 확률과 치명타 배율을 가진 최종 유닛입니다.
- 히든 카드는 가장 우측에 잠금 상태로 표시되며, 실제 융합 후 활성화됩니다.
