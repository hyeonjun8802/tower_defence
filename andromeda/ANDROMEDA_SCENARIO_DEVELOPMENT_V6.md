# ANDROMEDA Scenario Development V6

## 목적
안드로메다 기획서에서 남아 있던 신규 타워 3종과 최종 보스 3페이즈를 기존 전투 엔진을 깨지 않는 범위에서 실제 런타임에 연결했습니다.

## 추가 구현

### T01 공명 타워
- 해금: 3성역 / 4-3 공명 파편 클리어 보상
- 역할: 보호막 약화, 공명 표식, 장갑 약화
- 임시 썸네일: crystal 계열 이미지 alias 사용

### T02 중력 렌즈 타워
- 해금: 7성역 / 5-2 중력 렌즈 클리어 보상
- 역할: 단일 감속, 소형 중력장 감속, 빠른 적 러시 대응
- 임시 썸네일: void 계열 이미지 alias 사용

### T03 성흔 프리즘 타워
- 해금: 11성역 / 6-1 폐허 코어 클리어 보상
- 역할: 직선 관통 보조, 프리즘 링크, 행렬형 적 처리
- 임시 썸네일: laser 계열 이미지 alias 사용

### B03 공명 수호자 아스트라 3페이즈
- 1페이즈: 공명 보호막 / M02 보조 소환
- 2페이즈: 중력 폭주 / M05 보조 소환
- 3페이즈: 코어 공명 / M10 및 M08 압박 소환
- 적용 범위: 최종 15스테이지 final boss에서만 강화 페이즈 적용

## 안전 처리
- 신규 타워 타입은 10~12번으로 추가해 기존 0~8 기본 타워와 9번 히든 스타 엔진을 건드리지 않았습니다.
- 이미지가 없을 때도 빈칸이 되지 않도록 기존 thumb를 임시 alias로 사용합니다.
- `STAGE_TOWER_REWARDS_EXTRA`로 추가 보상을 분리해 기존 보상 테이블과 호환되도록 했습니다.
- 기존 15스테이지/맵/몬스터/타이머/BGM/강화 UI 로직은 유지했습니다.

## 아직 보류
- 실제 다중 route 엔진은 보류 유지.
- 신규 전용 이미지와 투사체 원화는 placeholder 경로만 등록.
