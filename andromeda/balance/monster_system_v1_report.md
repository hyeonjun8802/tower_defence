# 몬스터 시스템 확장 적용 리포트 v1

## 적용 원칙

- 타워 공격력/공속/합성/장판/강화/BGM/맵/버튼 로직은 수정하지 않음
- 몬스터 생성, 몬스터 능력, 몬스터 첫 등장 안내 팝업만 수정
- `1-1, 1-2` 같은 서브 스테이지 기준이 아니라 전체 스테이지/행성 컨셉 기준으로 몬스터 풀이 확장되도록 구성

## 첫 등장 안내 팝업

- 몬스터가 실제로 처음 스폰되는 순간 작은 `ENEMY SCAN` 팝업 표시
- 같은 몬스터 설명은 같은 세션에서 반복 표시하지 않음
- 전투 진행을 강제로 멈추지 않는 작은 팝업으로 구현해 기존 전투 흐름 침범 최소화
