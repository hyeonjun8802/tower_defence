# ANDROMEDA STAGE MAP DESIGN REVIEW V8

## 검토 요약
안드로메다 스테이지맵은 15개 노드 확장 후 구조는 정상이나, 디자이너 관점에서 아래 문제가 남아 있었다.

1. 외곽 노드와 최종 보스 노드의 glow가 작은 화면에서 가장자리나 주변 노드와 가까워 보일 수 있음
2. 고정 SVG route가 CSS로 보정된 노드 중심과 일부 어긋날 수 있음
3. 모바일에서는 라벨/타입 배지가 숨겨져 노드 의미 구분이 약해짐
4. portrait 짧은 화면에서 stageMapInner의 min-height가 정보 패널 영역을 밀 수 있음
5. 선택된 현재 노드의 시각 우선순위가 보스/위험 노드에 비해 약할 수 있음

## 적용 보완
- 15개 노드 좌표를 재정렬하여 외곽/중간/내부/코어 구간 간격을 보정했다.
- route SVG를 고정 path가 아니라 실제 노드 중심 기준으로 동기화하도록 보완했다.
- 작은 화면에서는 텍스트 배지 대신 컬러 dot 배지를 유지해 의미 구분을 살렸다.
- 모바일/짧은 가로모드의 stageMapInner min-height 압박을 제거했다.
- 현재 선택 노드의 glow/outline을 강화했다.
- locked 노드의 채도와 밝기를 조금 낮춰 active/unlocked와 시각 위계를 분리했다.
