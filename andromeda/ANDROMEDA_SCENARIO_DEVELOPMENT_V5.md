# Andromeda Scenario Development v5

## 추가 개발 범위

이번 v5에서는 기존 v4에서 보류되었던 시나리오 전투 요소 중, 기존 단일 route 엔진에 안전하게 얹을 수 있는 항목을 우선 반영했다.

## 구현 완료

### M03 위상 편이체
- 6초마다 1.2초간 위상 전환
- 위상 중 피해 25% 감소
- 낮은 회피율 유지
- 4-2 후반부터 소량 등장, 6-3 이후 교란 역할 강화

### M08 잔향 복제체
- HP 45% 이하에서 잔향 허상 1~2기 생성
- 허상은 약한 HP와 낮은 보상, 코어 피해 0
- 목적은 타겟 분산이며 게임오버를 직접 유발하지 않도록 설계

### M09 역장 견인체
- 5.4초마다 반경 132px 내 뒤쪽 적 최대 2기를 짧게 전진
- 물량을 압축해 M07/M10과 조합 압박 생성
- 5-5 후반, 6-3, 6-4 중심으로 투입

## 보완된 시나리오 구간
- 6-3 오염된 방어 프로토콜: M03/M08/M09 종합 테스트
- 6-4 수호자의 심장: 랜덤 버프 U 칸 + M09 견인 + M10 흡수 압박

## 아직 보류
- 완전한 다중 route 엔진
- 신규 타워 T01/T02/T03를 별도 타입으로 3개 추가하는 대규모 구조 변경
- 복잡한 보스 전용 UI

## 안전성 기준
- 기존 경로 엔진과 UI 레이아웃은 변경하지 않음
- 허상은 코어 피해 0으로 설정해 난이도 폭주 방지
- 견인은 route 위에서만 전진 처리
