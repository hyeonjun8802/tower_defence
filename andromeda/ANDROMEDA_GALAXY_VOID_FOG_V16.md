# Galaxy Map Void Fog v16

## 목적
은하수 맵에서 잠긴 은하가 너무 선명하게 보이는 문제를 수정한다.

## 반영
- 테스트/개발자 모드에서는 모든 은하를 선명하게 표시한다.
- 일반 모드에서 현재 열리지 않은 은하에 검은 공허 안개를 강하게 적용한다.
- 1번 은하만 열림:
  - 2번 은하: 흐릿한 preview fog
  - 3, 4번 은하: 거의 보이지 않는 deep void fog
- 2번 은하까지 열림:
  - 3번 은하: 흐릿한 preview fog
  - 4번 은하: deep void fog
- 3번 은하까지 열림:
  - 4번 은하: preview fog

## 변경 범위
- CSS 시각 보정만 적용
- 은하 해금/저장/전투/스테이지 로직 변경 없음
